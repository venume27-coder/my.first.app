# SlideNovaBot — промо-ролик (Remotion)

Вертикальный рекламный ролик для Telegram-бота [@SlideNovaBot](https://t.me/SlideNovaBot).
1080×1920, 30 fps, 52 с, H.264. Готовый файл: `out/slidenova-promo.mp4`.

## Быстрый старт

```bash
npm install
npm start            # Remotion Studio — предпросмотр в браузере
npm run build        # рендер → out/slidenova-promo.mp4
npm run stills       # превью PNG из середины каждой сцены → out/previews/
npm run stills -- --guides   # то же, с разметкой safe-зоны
```

## Что где лежит

| Путь | Что там |
| --- | --- |
| `src/config.ts` | **Всё, что обычно правят**: цвета, тексты, тайминги сцен, громкость музыки, бегущая строка |
| `src/fonts.ts` | Шрифты (Google Fonts через `@remotion/google-fonts`) |
| `src/scenes/` | 9 сцен, по компоненту на сцену |
| `src/components/` | Общие элементы: зерно, стикеры, 3D-телефон, Telegram-чат, marquee, глитч, мини-слайды |
| `src/Promo.tsx` | Сборка: склейки, глитч, zoom-punch на битах, музыка |
| `public/music.mp3` | Ваш трек (положите сюда) |
| `public/screens/` | Ваши скриншоты бота (необязательно) |

## Музыка

Сейчас в `public/music.mp3` лежит трек, сгенерированный кодом (`scripts/make_music.py`, 120 BPM,
ля минор): тиканье часов в хуке, дроп на «Есть решение», удары на каждой склейке, брейкдаун в
«Переходах», финальный аккорд. Пересобрать его: `pip install numpy scipy imageio-ffmpeg && npm run music`.

Чтобы поставить свой трек, замените `public/music.mp3` и перерендерьте. Если файла нет, ролик рендерится без звука.
Все сцены и анимации сидят на сетке **120 BPM** (1 бит = 15 кадров = 0,5 с), поэтому трек на 120 BPM
ляжет ровно. Громкость и длина затухания в конце: `MUSIC` в `src/config.ts`.

## Скриншоты бота

Положите PNG/JPG в `public/screens/` (берутся по алфавиту):
`1.png` пойдёт в телефон в сцене «Как работает», `2.png` в сцену «Картинки от ИИ».
Если папка пуста, интерфейс Telegram рисуется кодом.

## Как поменять

- **Тексты**: объект `TEXTS` в `src/config.ts`.
- **Цвета**: `COLORS` (палитра) и `MESH` (цвета фонового градиента каждой сцены) в `src/config.ts`.
- **Длительность сцен**: `SCENE_BEATS` в `src/config.ts` (в битах). Если меняете, поправьте
  тот же список в `scripts/stills.mjs`.
- **Safe-зона**: `SAFE` в `src/config.ts` (сейчас 120 px сверху, 250 px снизу).
